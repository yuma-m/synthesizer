synthesizer
===========

A simple virtual analog synthesizer written in Python.

Installation
------------

.. code-block:: bash

   pip install synthesizer

To play sounds through the speaker with :class:`~synthesizer.player.Player`, install the ``audio`` extra
(requires `PortAudio <https://www.portaudio.com/>`_):

.. code-block:: bash

   pip install "synthesizer[audio]"
